
========================================
       启动脚本乱码问题解决方案
========================================

【问题现象】
- 双击启动.bat提示乱码
- 提示"不是内部或外部命令"

【解决方案】

方案一：使用"启动_最简单.bat"（推荐）
- 直接双击"启动_最简单.bat"
- 这个脚本最简单，不会有编码问题

方案二：使用"启动_简化版.bat"
- 双击"启动_简化版.bat"
- 比原版简单，兼容性更好

方案三：手动启动（最可靠）
1. 打开命令行（Win+R，输入cmd）
2. cd 到项目目录
3. 输入：npm start

方案四：重新保存脚本编码
1. 用记事本打开启动.bat
2. 点击"文件" - "另存为"
3. 编码选择"ANSI"
4. 保存，覆盖原文件

【快速测试】
先在命令行测试：
1. Win+R，输入cmd
2. 输入：node -v
   如果显示版本号，说明Node.js已安装
3. cd 到项目目录
4. 输入：npm start
