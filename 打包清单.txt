
========================================
       Excel批量生成工具 V1.1 - 打包清单
========================================

【必须打包的文件】

index.html                      - 前端页面（必须）
server.js                       - 后端服务器（必须）
package.json                    - 项目配置（必须）
package-lock.json               - 依赖锁定文件（必须）
启动.bat                        - Windows 启动脚本（必须）
启动.sh                         - macOS/Linux 启动脚本（可选）
使用说明_便携版.txt             - 使用说明（推荐）
README.md                       - 详细文档（可选）

【不需要打包的文件】

node_modules/                   - 目标电脑上重新安装
uploads/                        - 运行时自动创建
templates/                      - 运行时自动创建
.git/                          - Git 相关
.gitignore                     - Git 相关

【打包步骤】

1. 新建一个文件夹，命名为：Excel批量生成工具_V1.1

2. 将以下文件复制进去：
   - index.html
   - server.js
   - package.json
   - package-lock.json
   - 启动.bat
   - 启动.sh
   - 使用说明_便携版.txt
   - README.md（可选）

3. 将文件夹压缩成 ZIP 包

【目标电脑使用步骤】

1. 解压 ZIP 包

2. 安装 Node.js（首次使用）
   - 访问 https://nodejs.org/
   - 下载并安装 LTS 版本

3. 双击"启动.bat"

4. 等待服务器启动

5. 浏览器访问：http://localhost:3000

├── package-lock.json
├── 启动.bat

├── 使用说明_便携版.txt
└── README.md
