# Excel批量生成工具 V1.0

## 📖 项目简介

Excel批量生成工具是一款基于Node.js开发的Web应用程序，专门用于批量生成带有图片的Excel文件。支持模板化管理、数据导入、图片自动匹配和批量导出功能。

**版本**: V1.0  
**更新时间**: 2026-05-13  
**开发作者**: CMCC-LIGE-13988819329  
**技术栈**: Node.js + Express + SheetJS + Sharp

---

## ✨ 核心功能

### 1. 📋 模板管理
- 手动创建Excel模板
- 导入已有Excel模板
- 可视化编辑字段配置
- 支持多种字段类型（文本、日期、数字、图片）

### 2. 📊 数据导入
- 支持CSV和Excel格式
- 自动识别字段类型
- 智能字段映射
- 数据验证和错误提示

### 3. 🖼️ 图片管理
- 单张图片上传
- ZIP压缩包批量上传
- 支持多种图片格式（JPG、PNG、GIF、BMP、WebP）
- 自动图片压缩优化
- 文件夹结构自动识别

### 4. ⚙️ 批量生成
- 自动匹配图片和数据
- 自定义文件名规则
- 支持文件名前缀和后缀
- 一键下载所有生成的Excel文件

### 5. 🔧 实用工具
- 一键清空所有数据
- 实时预览功能
- 服务器状态监控
- 图片文件夹管理

## 📝 使用教程

### 第一步：创建/导入模板

#### 方式一：手动创建模板
1. 点击 **"📋 手动创建模板"** 按钮
2. 点击 **"📝 添加行"**
3. 输入字段信息：
   - **显示名称**：界面显示的名称（如：小区名称）
   - **数据字段名**：英文字段名（如：CommunityName）
   - **字段类型**：选择对应类型（文本/日期/数字/图片）
   - **可替换**：勾选允许数据替换

#### 方式二：导入Excel模板
1. 点击 **"📥 导入模板"** 按钮
2. 上传已有的Excel模板文件
3. 在弹出的字段配置中调整字段信息
4. 确保图片字段的 **"字段类型"** 设置为 **"图片"**

### 第二步：导入数据

1. 点击步骤3的 **"📥 导入数据"** 按钮
2. 上传包含数据的CSV或Excel文件
3. 系统会自动识别字段并显示预览
4. 检查数据是否正确

### 第三步：上传图片

#### 上传ZIP压缩包（推荐）
1. 点击步骤4的 **"📦 上传ZIP文件"** 按钮
2. 选择包含图片的ZIP压缩包
3. ZIP结构要求：

```
📦 图片压缩包.zip
└── 文件夹1/
│   ├── logo.jpg
│   ├── photo.png
│   └── image.jpg
├── 文件夹2/
│   └── cover.png
└── ...
```

**重要**：文件夹名称必须与数据中的图片字段值完全一致！

#### 单独上传图片
1. 点击 **"🖼️ 选择图片"** 按钮
2. 选择要上传的图片文件
3. 图片会自动压缩并保存

### 第四步：配置生成选项

1. 选择输出文件名使用的字段
2. 设置文件名前缀（可选）
3. 设置文件名后缀（可选）
4. 选择图片匹配规则：
   - **使用第一张**：选择文件夹中的第一张图片
   - **精确匹配**：查找特定名称（logo/image/cover等）
   - **包含关键字**：文件名包含关键字即匹配

### 第五步：批量生成

1. 点击 **"🚀 开始批量生成"** 按钮
2. 系统会显示生成进度
3. 生成完成后，点击 **"📥 下载所有文件"** 下载ZIP包

### 数据Excel格式

```
  └── 古城区茨满村四组2号一体化RRU-LHWQ-004/  ← 必须与数据值一致
      ├── logo.jpg
      ├── photo.png
      └── image.jpg
```

## 🎯 图片识别规则

系统支持三种图片匹配规则：

| 规则 | 说明 | 优先级 |
|------|------|--------|
| **精确匹配** | 查找名为 logo、image、cover、photo 的文件 | 最高 |
| **关键字匹配** | 文件名包含 logo、image、cover、photo、pic 等关键字 | 中 |
| **使用第一张** | 选择文件夹中按字母排序的第一张图片 | 最低 |

**匹配顺序**：精确匹配 → 关键字匹配 → 使用第一张

## ❓ 常见问题

### Q1: 图片没有成功插入到Excel中？
**可能原因**：
- 字段类型未设置为"图片"
- 数据中图片字段的值为空
- ZIP文件夹名称与数据中的图片字段值不一致
- 文件夹中没有图片文件

**解决方法**：
1. 检查模板中图片字段的"字段类型"是否为"图片"
2. 检查数据文件中图片字段列是否有值
3. 检查ZIP解压后的文件夹名称是否与数据值完全一致

### Q2: 上传ZIP文件没有反应？
**可能原因**：
- 未通过服务器访问页面（使用了file://协议）

**解决方法**：
必须通过 http://localhost:3000 访问，不能直接双击打开index.html

### Q3: 文件名生成不正确？
**可能原因**：
- 未选择正确的"文件名使用的字段"
- 字段值为空或包含非法字符

**解决方法**：
1. 在步骤5中正确选择文件名使用的字段
2. 确保数据中该字段有值

### Q4: 如何查看详细的处理日志？
**解决方法**：
1. 按 F12 打开浏览器开发者工具
2. 切换到 Console 标签
3. 点击生成按钮，查看详细日志

### Q5: 如何清空所有上传的图片？
**解决方法**：
在界面底部找到 **"🗑️ 清空所有图片"** 按钮，点击即可清空。
