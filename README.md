# Excel批量生成工具 V1.0

## 📖 项目简介

Excel批量生成工具是一款基于Node.js开发的Web应用程序，专门用于批量生成带有图片的Excel文件。支持模板化管理、数据导入、图片自动匹配和批量导出功能。

**版本**: V1.0  
**更新时间**: 2026-05-13  
**技术栈**: Node.js + Express + SheetJS + ExcelJS
**开发作者**: CMCC-LIGE-13988819329

---

## ✨ 核心功能

### 1. 📋 模板管理
- 导入已有Excel模板
- 可视化编辑字段配置
- 支持多种字段类型（文本、日期、数字、图片）
- 模板保存和加载功能

### 2. 📊 数据导入
- 支持Excel格式数据导入
- 自动识别字段类型
- 智能字段映射
- 支持两行表头（第一行中文，第二行英文）

### 3. 🖼️ 图片管理
- ZIP压缩包批量上传
- 支持中文文件名解压
- 文件夹结构自动识别
- 图片自动匹配插入

### 4. ⚙️ 批量生成
- 自动匹配图片和数据
- 显示名称行保留
- 变量名行删除
- 示例数据行替换
- 一键下载所有生成的Excel文件（ZIP包）

### 5. 👁️ 预览功能
- 实时预览第一条数据
- 显示替换效果
- 高亮已替换字段和图片占位

## 🚀 快速开始

### 环境要求
- Node.js v14.0.0 或更高版本
- npm 或 yarn 包管理器

### 安装步骤

1. **克隆或下载项目**
```bash
git clone https://github.com/greensky113/excel-batch-generator.git
cd excel-batch-generator
```

2. **安装依赖**
```bash
npm install
```

3. **启动服务器**
```bash
npm start
```

4. **访问应用**
打开浏览器访问: http://localhost:3000

## 📝 详细使用教程

### 第一步：准备模板Excel

#### 模板格式说明

您的模板应该采用**每个字段占3行**的格式：

| 行号 | 列A | 列B | 说明 |
|------|------|------|------|
| 1 | 小区名称 | 方案制定人 | **显示名称** → 保留！ |
| 2 | CommunityName | PlanMaker | **变量名行** → 删除！ |
| 3 | 示例小区 | 张三 | **示例数据** → 替换！ |
| 4 | 方案制定时间 | 方案审核人 | **显示名称** → 保留！ |
| 5 | PlanMakeTime | PlanAuditor | **变量名行** → 删除！ |
| 6 | 2026-05-06 | 李四 | **示例数据** → 替换！ |
| 7 | 基站照片 | | **显示名称** → 保留！ |
| 8 | jizhanzhaopian | | **变量名行** → 删除！ |

#### 关键说明
- **第一行**：中文显示名称（保留）
- **第二行**：英文字段名（删除，不显示）
- **第三行**：示例数据（替换为实际数据）
- 循环往复...

### 第二步：导入模板

1. 点击 **"📥 导入模板"** 按钮
2. 上传您准备好的Excel模板文件
3. 在弹出的字段配置中，**重要**：
   - 检查并修改字段类型（图片字段必须设置为"图片"）
   - 确认"可替换"选项已勾选
4. 点击 **"💾 保存模板修改"** 保存您的配置
5. （可选）点击 **"📥 下载当前模板"** 下载保存好的模板
6. 点击 **"✅ 完成配置"**

### 第三步：导入数据

1. 准备数据Excel文件
   - 第一行：表头（与模板显示名称一致）
   - 第二行：英文字段名（可选，仅用于字段映射）
   - 第三行开始：实际数据

2. 点击 **"📥 导入数据"** 按钮
3. 上传数据Excel文件
4. 查看导入的数据预览，确认数据正确

### 第四步：上传图片ZIP

1. 准备图片ZIP压缩包
   - 创建文件夹，文件夹名称与数据中图片字段值一致
   - 在文件夹中放入图片文件
   - 将所有文件夹打包成ZIP

   **示例结构**：
   ```
   📦 基站照片.zip
   ├── 古城区茨满村四组2号一体化RRU-LHWQ-004/
   │   ├── photo1.jpg
   │   └── photo2.jpg
   └── 古城区茨满村四组2号一体化RRU-LHWQ-005/
       └── photo.jpg
   ```

2. 点击 **"📦 上传ZIP文件"** 按钮
3. 选择您的ZIP文件
4. 查看已识别的图片文件夹列表

### 第五步：配置变量名行

1. 在 **"要删除的行（变量名行）"** 输入框中
2. 输入需要删除的变量名行的行号，用逗号分隔
3. 例如：`2,5,8` 表示删除第2、5、8行

### 第六步：预览和生成

1. 点击 **"👁️ 预览第一条数据"** 查看效果
2. 确认预览正确后
3. 点击 **"🚀 开始批量生成"**
4. 等待生成完成
5. 下载ZIP包，包含所有生成的Excel文件

## ❓ 常见问题

### Q1: 图片没有成功插入到Excel中？
**可能原因**：
- 模板中图片字段的类型未设置为"图片"
- 数据中图片字段的值为空
- ZIP文件夹名称与数据中的图片字段值不一致
- 文件夹中没有图片文件

**解决方法**：
1. 在导入模板后的字段配置中，确保图片字段的"字段类型"设置为"图片"
2. 检查数据文件中图片字段列是否有值
3. 检查ZIP解压后的文件夹名称是否与数据值完全一致

### Q2: 上传ZIP文件没有反应？
**可能原因**：
- 未通过服务器访问页面（使用了file://协议）

**解决方法**：
必须通过 http://localhost:3000 访问，不能直接双击打开index.html

### Q3: 变量名行没有被删除？
**解决方法**：
在步骤5的"要删除的行（变量名行）"输入框中，正确输入需要删除的行号，例如：`2,5,8`

### Q4: 如何查看详细的处理日志？
**解决方法**：
1. 按 F12 打开浏览器开发者工具
2. 切换到 Console 标签
3. 点击生成按钮，查看详细日志
